# 🚀 De Call Center para Suporte de TI

Este repositório documenta minha transição de carreira: de atendente de call center para suporte técnico em TI.

## 🎯 Objetivo
Conseguir minha primeira vaga como Suporte Técnico / Help Desk Jr, documentando aqui tudo que estudo e pratico ao longo do processo.

## 🧠 Ponto de partida
- Experiência prévia com hardware, montagem e formatação de PC
- Uso Linux no dia a dia (CachyOS) e já tenho familiaridade básica com o sistema
- Experiência de atendimento ao cliente (call center) — trago isso como diferencial pra área de suporte

## 📚 O que estou estudando
- [ ] Fundamentos de Linux (administração, usuários, permissões, shell script, cron)
- [ ] Redes (DNS, DHCP, FTP, HTTP, Proxy, Firewall, SSH)
- [ ] Samba / LDAP (equivalente Linux de Active Directory)
- [ ] Cisco Networking Academy — Networking Basics
- [ ] Microsoft Learn — Windows Server e Active Directory fundamentals
